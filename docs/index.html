The machine is good. That's the problem.

It gets almost any fair clue on the first try, so “can you make it guess” is not much of a question. The real one is how few characters can you do it in — and that turns out to be a genuinely steep curve. Measured against the real model:

60 chars100%
40 chars100%
25 chars90%
15 chars67%

So every puzzle shows par — the median clue length among everyone who has solved it. Your score is not a number in a vacuum; it is a number next to everyone else's.

Thirty seconds a day

Built in the open

Kotlin Multiplatform — around 94% of the code is written once and runs on both Android and iOS, including every screen. The API is a Cloudflare Worker, the guesses come from Gemini, and subscriptions run through RevenueCat.

The whole thing is public, including the part where a substring check for banned words kept rejecting delight, sandwich and window until someone measured it. See for yourself.
